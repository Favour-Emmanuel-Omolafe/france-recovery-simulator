## 📌 Overview
The **France 2030 Simulator** is a prescriptive analytics engine and interactive SaaS dashboard built to solve the **Macroeconomic Trilemma**: balancing a national budget (EU 3.0% deficit compliance) while maintaining economic growth and preventing social collapse (General Strikes). 

Instead of relying on static, linear assumptions, this model incorporates real-world economic shocks, non-linear demographics, and European Central Bank (ECB) monetary constraints.

## 🚀 Key Features
*   **The AI Auto-Solver:** An algorithmic optimiser that automatically tests thousands of policy combinations to prescribe the exact mathematical path to solvency.
*   **Executive Data Visualization:** Features a consulting-style **Deficit Waterfall Bridge** and a gamified **Strike Risk Speedometer** built with Plotly.
*   **Real-World Policy Levers:** Replaces generic austerity with specific French political realities, including the Statutory Retirement Age, the Wealth Tax (ISF), and unemployment benefit drags.
*   **Global Macro Shocks:** Stress-tests the economy against external variables like ECB Interest Rate hikes and Geopolitical Energy Crises.

## 🛠️ Tech Stack
*   **Frontend:** Streamlit (Custom Dark Theme UI)
*   **Backend:** Python (System Dynamics Modelling)
*   **Data Processing:** Pandas, NumPy
*   **Data Visualisation:** Plotly Express, Plotly Graph Objects
